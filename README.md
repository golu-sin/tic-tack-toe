# Tic Tac Toe

## Project Overview

Tic Tac Toe is a classic two-player game built using HTML, CSS, and JavaScript. The game allows players to take turns placing X and O on a 3×3 grid. The first player to align three symbols horizontally, vertically, or diagonally wins the game.

---

## Features

- Interactive 3×3 game board
- Two-player gameplay
- Win detection
- Draw detection
- Restart game functionality
- Responsive design
- Clean and simple interface

## How to Play

1. Open the game in a web browser.
2. Player X starts first.
3. Players take turns selecting empty cells.
4. The first player to get three symbols in a row wins.
5. If all cells are filled and no player wins, the game ends in a draw.
6. Use the restart button to play again.
